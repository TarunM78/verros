# pip-based setup for pygeartrain (alternative to environment.yml / conda).
#
#   py -3.12 -m venv .venv
#   .venv\Scripts\python -m pip install -r requirements.txt
#   .venv\Scripts\python -m pip install --no-deps git+https://github.com/eelcohoogendoorn/pycomplex.git
#
# Notes:
# - numpy is pinned < 2 only because the optional numga reference needs NumPy 1.x integer promotion.
# - numga is optional: pygeartrain/core/pga.py no longer needs it; the pin below is only used by
#   test_pga as a reference implementation. It is the last commit before numga's 2026-09 rewrite.
# - pycomplex declares two C-only deps (fastcache, pycosat) that have no Windows wheels; it is
#   installed with --no-deps and shimmed by .venv/Lib/site-packages/fastcache.py (functools.lru_cache)
#   and .venv/Lib/site-packages/pycosat.py (backed by python-sat).
# - Optional, for STEP export (pygeartrain/step_export.py, GUI "Export STEP solids"): CadQuery. A plain
#   `pip install cadquery` upgrades numpy to 2.x (via nlopt>=2.9), so install it without deps instead:
#   pip install --no-deps cadquery && pip install "cadquery-ocp>=7.9.3.1,<8" ezdxf "multimethod<2" runtype casadi nlopt==2.7.1 typing_extensions
#   (numba and trame are only needed by cadquery.vis and are left out.)
